# Rupika Jewels — Final Premium Website

Final V1 build for Rupika Jewels.

## Included
- Premium responsive luxury jewellery UI
- Rupika transparent logo
- 288 curated jewellery product images sourced from the supplied RJKR + RJKRK archives
- 8 high-quality featured pieces selected for the home page
- High-quality landscape hero image
- Searchable catalogue
- Product detail pages
- WhatsApp enquiry buttons
- Instagram, LinkedIn and optional full-catalog links
- Mobile navigation
- 3-column desktop product grid, 2-column tablet, 1-column mobile
- No horizontal overflow
- Typography: DM Serif Display for headings + Manrope for UI/body
- No generated imagery

## Image curation
Obvious non-jewellery/statue images, third-party branded/graphic images, and images with clearly visible unrelated branding were excluded rather than having third-party marks digitally erased.
